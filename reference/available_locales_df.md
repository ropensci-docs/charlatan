# Available locales

A data.frame of locales available in charlatan. All localized providers
are linked in the documentation.

## Format

A data frame with 45 rows and 4 variables:

- Language:

  language two letter code

- Country:

  country two letter code

- Variant:

  a variant code, if applicable

- Name:

  official locale two letter code
