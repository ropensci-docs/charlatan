# Person Provider for Czech (Czech Republic)

Person Provider for Czech (Czech Republic)

Person Provider for Czech (Czech Republic)

## Value

A PersonProvider object that can create names.

## Details

Note for female and male components that we fall back on generic
versions if the locale doesn't provide a male/female version. e.g., if
no female first name we use first name

## Examples

``` r
x <- PersonProvider_cs_CZ$new()
x$locale
#> [1] "cs_CZ"
x$render()
#> [1] "JUDr. Miloslava Šimková"
x$first_name()
#> [1] "Marek"
x$first_name_female()
#> [1] "Daniela"
x$first_name_male()
#> [1] "Robin"
x$last_name()
#> [1] "Benešová"
x$last_name_female()
#> [1] "Horáková"
x$last_name_male()
#> [1] "Soukup"
```
