# Person Provider for Nepali (Nepal)

Person Provider for Nepali (Nepal)

Person Provider for Nepali (Nepal)

## Value

A PersonProvider object that can create names.

## Details

Note for female and male components that we fall back on generic
versions if the locale doesn't provide a male/female version. e.g., if
no female first name we use first name

### Method `clone()`

The objects of this class are cloneable with this method.

#### Arguments

- `deep`:

  Whether to make a deep clone.

## Examples

``` r
x <- PersonProvider_ne_NP$new()
x$locale
#> [1] "ne_NP"
x$render()
#> [1] "राम के.सी."
x$first_name()
#> [1] "मन्ना"
x$first_name_female()
#> [1] "मेरिना"
x$first_name_male()
#> [1] "रविन्द्र"
x$last_name()
#> [1] "वज्राचार्य"
x$last_name_female()
#> [1] "(श्रेष्\nठ)"
x$last_name_male()
#> [1] "श्रेष्\nठ"
```
